# プレゼンテーションとエクスポート

> English version: [English](../presenting-and-export.md)

Canvas、Desktop、CLI は同じレンダラーで描画するため、聞き手に見える結果は変わりません。
発表の準備と書き出しに使える機能は、利用環境によって異なります。

## プレゼンテーション機能を比較する

| 機能 | Canvas Extension | Desktop | CLI |
| --- | --- | --- | --- |
| 現在のスライド | 対応 | 対応 | 対応 |
| 次のスライドのプレビュー | 発表者ビュー | メインウィンドウ | 発表者ビュー |
| スピーカーノート | 発表者ビュー | メインウィンドウ | 発表者ビュー |
| スライド一覧 | 対応 | 対応 | 対応 |
| 外部の投影用ウィンドウ | 対応 | 対応 | 対応 |
| 操作の同期 | 対応 | 対応 | 対応 |
| 投影側の全画面表示 | `F11` | `F11` | `F11` |
| 16:9 のクリッピング確認 | 対応 | 非対応 | `markdstage inspect` |
| PDF エクスポート | 対応 | 非対応 | `markdstage export --output slides.pdf` |
| 編集可能な PowerPoint エクスポート | 対応 | 非対応 | `markdstage export --output slides.pptx` |
| Surface Pen | Windows で対応 | 投影用ウィンドウ表示中に対応 | 非対応 |

## 発表者ビューを準備する

Canvas の発表者ビュー、または Desktop のメインウィンドウを開き、次の点を確かめます。

- 現在のスライドが合っている
- 次のスライドのプレビューが役に立つ
- スピーカーノートに発表者向けの内容だけが書かれている
- スライド一覧のタイトルが分かりやすい

![プレゼンテーション用に準備した Canvas の発表者ビュー](../images/canvas-presenter-view.png)

## 投影用ウィンドウを開く

- **Canvas:** **More controls > External window**、または発表者ビューの
  **Start presentation** を選びます。
- **Desktop:** **Start presentation** を選びます。

開いたウィンドウを投影用ディスプレイへ移します。`F11` で全画面にし、
`Esc` で戻します。発表者側と投影側は同じスライドに揃って動きます。

## 固定 16:9 出力を確認する

Canvas Extension で **More controls > Output preview** を選びます。PDF 出力と同じ
1280x720 のタイポグラフィ、余白、内容量の制限でスライドをレターボックス表示します。

内容が固定ページに収まらない場合は、クリッピング警告が出ます。

![現在のスライドが縦方向にクリップされることを示す 16:9 プレビュー警告](../images/canvas-layout-warning.png)

内容を減らす、スライドを分ける、合ったレイアウトに変える、明示的に大きくした
コンテンツサイズを戻す、といった方法で警告を解消します。

デッキの PDF レイアウトを Copilot に確認させ、直すべきページを洗い出すこともできます。

## PDF を書き出す

1. デッキを開いた後に元ファイルを変更した場合は、読み込み直します。
2. **More controls > Output preview** を選び、クリッピング警告を解消します。
3. **More controls > Export PDF** を選びます。
4. ワークスペースにできた PDF を開き、全ページを確認します。

Markdown からデッキを読み込んだ場合、PDF のファイル名は元ファイル名をもとに決まります。
書き出した PDF には、裏表紙を含む各スライドが 16:9 で1ページずつ入り、
背景、画像、シンタックスハイライト付きコード、Mermaid、Architecture 図もそのまま出ます。

スピーカーノートと Architecture の編集コントロールは PDF には出ません。

## 編集可能な PowerPoint を書き出す

1. デッキを開いた後に元ファイルを変更した場合は、読み込み直します。
2. **More controls > Output preview** を選び、クリッピング警告を解消します。
3. **More controls > Export PowerPoint** を選ぶか、
   `markdstage export slides.md --output slides.pptx` を実行します。
4. 生成されたプレゼンテーションを開き、全スライドを確認します。

PowerPoint のネイティブオブジェクトは編集可能なまま残ります。ネイティブに表現できない要素は、
スライド全面の透明画像ではなく、それぞれの表示範囲に切り出したフォールバック画像になります。

| Markdown の要素 | PowerPoint での扱い |
| --- | --- |
| 見出し、段落、リンク | 編集可能なネイティブテキスト |
| 箇条書き・番号付きリスト | 連続するリストごとに1つの編集可能なテキストボックス。ネストした階層も含み、箇条書き記号の色はスライドテーマに従う |
| 単純な表 | 編集可能なネイティブの表 |
| フェンス付きコードブロック | ネイティブテキスト。シンタックスハイライト、インデント、空行、等幅フォント、背景、枠線、アクセント線が編集可能な状態で残る |
| Architecture DSL のノード、グループ、コネクターラベル | 文字を内包するオートシェイプ |
| Architecture DSL のアイコン | 図形の前面に置かれる透明画像 |
| 画像（対応する SVG を含む） | 個別の画像 |
| スピーカーノート | スライドのノート欄にプレーンテキストとして出力 |
| Mermaid の図 | 編集可能なネイティブ図形、テキスト、コネクター。未対応の SVG 詳細は要素ごとのフォールバック画像 |
| 装飾背景、グラデーション、コードブロックの影 | フォールバック画像 |
| 未対応の画像効果や HTML/CSS | フォールバック画像 |

書き出し結果にはフォールバック内容が明示され、黙って削除されることはありません。

書き出したプレゼンテーションには、デッキで使われたテーマごとにスライドマスターが作られ、
`title`、`default`、`center`、`section`、`backcover` の名前付きレイアウトが含まれます。
テーマ共通の背景と上部バーはレイアウト画像に置かれ、対応する表紙ロゴはレイアウト上の
個別画像になります。フッター罫線、ページ番号の枠、キッカーマークなどのスライド固有の装飾は
描画範囲だけに切り出されます。

編集可能な日本語テキストでは、東アジア用のプライマリーフォントとして
游ゴシック（Yu Gothic）が設定されます。英数字には、レンダリングされたスライドで
選択されたフォントが引き続き使われます。編集可能なテキストは校正対象外として
書き出されるため、PowerPoint のスペルチェックや文章校正の波線は表示されません。

PowerPoint は PDF と同じ 13.333333 x 7.5 インチ、同じメモリ上のスナップショットから
生成され、一時的なスライド差し替えと自動の裏表紙も含みます。Architecture の編集コントロールは
含みません。Chromium との完全一致や汎用 HTML/CSS 変換は対象外です。
