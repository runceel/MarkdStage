# トラブルシューティング

> English version: [English](../troubleshooting.md)

## Canvas Extension が使えない

- リポジトリに `.github/extensions/markdstage/` があるか確かめます。ない場合は、
  信頼できるリリースタグから Extension をユーザースコープにインストールします。
- インストールしたらプロジェクトを開き直します。
- Canvas を直接開く場合は、Canvas ID `MarkdStage` を指定します。

## Desktop のプレビューが表示されない

Microsoft Edge WebView2 Runtime をインストールするか修復してから、MarkdStage Desktop を再起動します。
ユーザープロファイルがローカルアプリケーションデータフォルダーに書き込めるかも確かめてください。

## Store 版のコマンドが見つからない、またはブラウザーが開く

新しいターミナルで `Get-Command markdstage -All` を実行します。Store のエイリアスが
見つからない、または無効になっている場合は Windows 設定の **アプリ実行エイリアス** を確認します。
npm 版が解決順で先にある場合はブラウザー UI、Store 版はネイティブアプリが開きます。
Store のエイリアスを直す目的で npm を追加する必要はありません。
詳細は[インストールガイド](installation.md)を参照してください。

## Desktop で表示できるがエクスポートに失敗する

ネイティブ表示には WebView2 を使いますが、PDF／PowerPoint 出力にはインストール済みの
Edge、Chrome、Chromium のいずれかも必要です。組織のポリシーでブラウザーのリモートデバッグが
許可されているか確認します。再実行の前に出力エラーを読みます。スライドを表示できることだけでは、
出力の前提条件を満たしているとは限りません。

## AI ツールが導入済みのスキルを検出しない

Desktop と AI ツールで同じワークスペースを使用します。**Install skills…** は
ワークスペースにファイルを置く機能であり、エージェントのグローバル設定ではありません。
正しい対象を選んだか確認し、AI ツールの手順に従って再読み込みしてください。
MarkdStage の更新後はスキルも更新し、競合が報告された場合は内容を確認します。

## Canvas の読み込み画面に Markdown ファイルが出てこない

- ファイル名が `.md` または `.markdown` で終わっているか確かめます。
- 開いているワークスペースの中にファイルがあるか確かめます。
- Git リポジトリでは、リポジトリルートがワークスペースルートです。

ワークスペースの外にあるパスは選べません。

## 思わぬ位置でスライドが分かれる

- `---` の前に空行を入れます。
- 区切りは、その行に `---` だけを書きます。
- フェンス付きコードブロックを閉じ忘れていないか確かめます。
- テキストのすぐ下に書いた `---` は、Setext 見出しとして解釈されることがあります。

## 保存しても表示が変わらない

- Canvas では **Refresh automatically on save** が有効か確かめます。
- Desktop では同じファイルを選んだままか確かめます。
- ファイルが空、読み取り不能、または内容が壊れていないか確かめ、問題があれば直します。
  壊れている間は最後に読めたデッキが表示され続け、次に有効な内容を保存した時点で元に戻ります。

## 画像が表示されない

- Markdown では `/assets/file.png` と書きます。
- Architecture DSL では `assets/file.png` と書きます。
- ファイルは Markdown と同じ場所か、ワークスペースルートの `assets/` に置きます。
- `..` でワークスペースの外へ出ないようにします。
- 大文字と小文字、拡張子を確かめます。

## カスタムテーマが読み込まれない

- `theme: custom` と、相対パスの `theme-file` を指定します。
- テーマは Markdown と同じ場所か、ワークスペースルートに置きます。
- CSS カスタムプロパティの宣言だけを書きます。
- セレクター、`@import`、`url()`、JavaScript、外部パスは取り除きます。
- `theme.json` の内容を確かめます。メタデータファイルが壊れている場合は無視されず、エラーになります。

## PDF でスライドが見切れる

Desktop、Canvas、npm UI で **More controls > Output preview** を選び、警告から該当ページを確かめます。
内容を減らすか、スライドを分けてください。`layout: center` は配置を変えるだけで使える領域は
増えないので、見切れの対策にはなりません。

## Mermaid や Architecture でエラーが出る

- フェンスの名前と閉じフェンスを確かめます。
- Mermaid の構文を確かめます。
- Architecture の JSON、要素 ID の重複、参照、位置、指定できる値かどうかを確かめます。
- 図のエラーを直している間も、スライドの他の内容は表示されたままです。

## Architecture の変更が保存できない

- Advanced editing には元ファイルにひも付くデッキが必要です。Desktop の一覧、または
  Canvas の **More controls > Open Markdown** で開いてください。
- 元ファイルに `architecture` ブロックが必要です。
- 元ファイルが外部で書き換えられた場合は、上書きせずに読み込み直します。
- レイアウトに従って配置されている子要素を手で動かす前に、親グループのレイアウトを解除します。

## 投影用ウィンドウを全画面にできない

投影用ウィンドウにフォーカスを移してから `F11` を押します。`Esc` でウィンドウ表示に戻ります。
他のアプリにキーが取られる場合は、OS のウィンドウ操作を使ってください。
